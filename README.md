# SelfSearch
Work in progress self-hosted search engine. This is in a very early development phase. Not recommended for production. Currently searching is extremely primitive, naive, and limited. There's no CSS of any kind currently. Search results just give the page title and link to the page.

## Dependencies
PHP, some kind of webserver, MariaDB or compatible, php-mysql plugin of some kind. See the [crawler](https://github.com/rainier39/SelfSearchCrawler) for its dependencies.
